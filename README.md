## 👍 🚀 Android Toolkit Library

Provide a lot of GUI toolkit and utilities function for Android application.
Powered by Bamboo Note Developer.

- **[Demo](https://play.google.com/store/apps/details?id=the.wind.library.sample)**
- **[Bamboo Note Application](https://play.google.com/store/apps/details?id=the.wind.bamboo.note)**

## 🔨 Installation

**Gradle** 

    allprojects {
        repositories {
            mavenCentral()
            maven { url 'https://jitpack.io' }
        }
    }

    dependencies {
	    implementation 'com.github.vuthaiduy1990:android-wind-library:v4.0.0'
    }

More installation repository here:  [JitPack](https://jitpack.io/#vuthaiduy1990/android-wind-library/v4.0.0)

## 📌 Features

**[Document](https://github.com/vuthaiduy1990/android-wind-library/wiki)**, **[Demo](https://play.google.com/store/apps/details?id=the.wind.library.sample)**, **[Bamboo Note Application](https://play.google.com/store/apps/details?id=the.wind.bamboo.note)**


### Rich GUI
- Button toolkit
- Checkbox toolkit
- Dialog, Popup and Menu
- Dropdown
- Search Box
- Tag Bog
- Wrapper of recycle view
- Calendar View that support both Solar and Lunar calendar

### Rich Utilities
- Simple wrapper of GSON
- Simple wrapper of SQLite
- Simple wrapper of File management
- Simple wrapper of crypto (encryption and decryption)
- Simple fake NLP searching
